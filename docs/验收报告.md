## 已知限制与未验证项

1. macOS 14/15 等其他系统版本、另一台 Mac 和 Intel 实机尚未测试；通用二进制构建不等于这些设备已通过验收。
2. Office 可能存在字体替换、分页和公式/图表差异。工作表选择经临时 XLSX 处理，复杂工作簿需要预览核对。
3. 网页使用当前渲染布局分页，不执行专门的 print-only CSS；懒加载、超高图片及复杂页面需检查预览。
4. 灰度输出采用 300 dpi 栅格页面，文字可搜索性与彩色矢量输出不同。
5. 当前清理由设置页手动触发，按默认 30/180 天保留策略执行。
6. 本地 HTML 只额外归档常见同名资源目录，不保证任意网站资源树离线完整。
7. 尚未覆盖所有物理参数组合，包括 A3、彩色、短边双面、多份逐份等现场效果；驱动映射已有校验。
8. 未做 Developer ID 公证，也未在受管理的同事电脑完成首次安装验证。

只有上述跨设备和现场检查完成后，才能声明全面验收完成。
