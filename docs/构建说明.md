# 构建与验证

## 工具

macOS，Apple Swift 6.0 或更新工具链；最低运行版本 macOS 14。可使用兼容的 Xcode 或 Command Line Tools。系统链接 PDFKit、AppKit、WebKit、CoreGraphics、SQLite 和 CUPS，没有 Swift 包下载依赖。

## 构建通用应用

在源码目录执行：

```sh
./scripts/build.sh "$PWD/dist"
```

脚本分别构建 arm64、x86_64，合并为通用可执行文件，装配应用并本地签名。LibreOffice 不进入主应用安装包。

创建安装镜像时，将应用与 Applications 的符号链接放入暂存目录，使用 `hdiutil create -srcfolder ... -format UDZO ...`。

具备 Developer ID 时可替换本地签名，并使用自己的公证凭据完成公证。源码与安装包不包含签名证书、账号或凭据。

## 自动自测

```sh
./scripts/test.sh
```

本地 CLI 工具链缺少 XCTest 时，自测入口仍可运行。它使用真实 PDF、图片、SQLite、文件导出和队列故障注入，不提交实体打印任务。`Tests/BatchPrintTests` 中另有 XCTest 测试，可在具备 XCTest 的 Xcode 环境运行 `swift test`。

为了复现现有 8 个文件的检查，可使用：

```sh
.build/debug/BatchPrint --self-test /tmp/batchprint-test-unique --samples '/路径/到/PDF文件夹'
```

`--samples` 入口用于本次固定的 8 文件验收集；需要恰好 8 个 PDF。每次使用新的自测目录，避免重复文件干扰。

## 结构

- Models / AppModel：参数模型、队列、恢复与 UI 状态。
- FileServices：快照、内容校验、SQLite、安全导出。
- Converter / WebRenderer / MarkdownRenderer / WorkbookPrintSettings：格式转换。
- PDFComposer：选页、纸张、旋转、缩放及灰度。
- PrinterBackend：CUPS 能力、提交、查询和取消；可注入打印机服务用于丢失响应测试。
- Views / WebImportView：三栏界面、预览、设置及网页登录。

开发期间无需 GitHub。若以后执行 GitHub 操作，须使用用户授权接口。
