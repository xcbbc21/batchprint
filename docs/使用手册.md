# 批量打印 1.0.1 使用手册

## 安装

适用于 macOS 14 或更新系统。打开安装镜像，将“批量打印.app”拖入“应用程序”，然后打开。

此交付为本地签名的小范围使用版本，未使用 Developer ID 公证。通过网络传给同事后，macOS 可能要求在“系统设置 → 隐私与安全性”确认打开。如果单位安全策略禁止未公证应用，应由管理员或持有 Developer ID 的开发者签名公证后再部署；无需关闭 Gatekeeper。

应用不需要管理员权限。PDF、图片、文本和网页处理使用系统框架。Word、Excel、PPT 等办公文件需要另行安装 LibreOffice：
1. 打开应用左下角“设置与依赖”。
2. 点击“打开官方下载页”，选择适合 Apple Silicon 或 Intel 的 macOS 版本。
3. 将 LibreOffice 拖入“应用程序”，手动打开一次。
4. 回到设置页，确认“已找到 LibreOffice”；如果安装位置不同，点击“选择 LibreOffice.app”。

不需要 Homebrew，不需要输入命令行。

## 打印到 PDF

1. 新建批次，添加文件，或将文件拖入文件列表。
2. 等待状态变为“待执行”，选择文件检查右侧输出预览。
3. 在“输出到”选择“打印到 PDF”。没有配置任何实体打印机也可以使用。
4. 设置纸张、方向、页码、缩放、旋转、彩色或灰度。
5. 点击“保存 PDF”，选择保存目录。
6. 每个源文件独立生成“原文件名-打印.pdf”；已有同名文件自动增加序号，不覆盖原文件。

PDF 模式禁用单双面、份数及逐份打印。不会为了“多份”而复制 PDF 页面。输出完成后，可点击“打开 PDF”或“在 Finder 中显示”。

灰度输出为 300 dpi 灰度页面图像；文字外观保留，但灰度 PDF 中的文字不会像彩色矢量输出一样保持可搜索性。大尺寸页面会增加文件大小。

## 实体打印

先在 macOS 系统设置中添加打印机，再在应用中选择它。若刚添加，可在“设置与依赖”刷新打印机。

除 PDF 模式共有参数外，实体打印可设置单面、长边双面、短边双面、份数及逐份打印。应用读取驱动能力，不能确认或不支持的组合会提示修改，不会静默换成另一种参数。

每个文件是一个独立打印任务。例如 A、B 各两份：输出 A 的两份，再输出 B 的两份；不是 A+B 成套输出。同一打印机一次跟踪一个本应用任务，其他应用的打印任务可能插入队列。

双面、纸张边缘和驱动颜色处理最终取决于具体设备。首次使用新打印机，建议只输出少量测试页。

## 批次参数与逐文件参数

右侧“整个批次”修改批次默认参数；“所选文件”只修改所选未锁定文件。可以按住 Command 多选文件后批量修改。

优先级是“逐文件覆盖 → 批次设置 → 创建时的模板参数”。已经输出或正在输出的文件会锁定参数；批次之后的修改不改变它们。通过“再次输出 / 重试”创建新任务，再调整参数。

页码格式如 `1-3,5`；支持 `3,1-2` 按指定顺序输出，重复页码只保留第一次出现。页码以转换后的 PDF 为准。

可拖动文件调整顺序；只在完整批次列表、无搜索过滤且未输出时调整顺序。批次模板可保存纸张、输出目标等参数。修改默认设置仅影响后续新批次。

## 格式与转换选项

- PDF：加密文件先点击“PDF 密码”，输入密码后重新准备；密码仅保留在会话内。
- Office：保留原始分页为默认行为，仍需检查字体替换、图表及分页。Office 加密文件暂不支持，先在原软件中解密另存。
- Excel：在“转换选项”输入工作表名称，用逗号分隔；留空保持原工作簿的可见工作表及打印设置。勾选“所有列适合一页宽”可避免宽表横向分成多页。设置经过临时 XLSX 应用，公式、图表和复杂格式应核对预览。
- CSV：在转换选项选择编码和分隔符，重新转换后检查列布局。
- TXT：支持 UTF-8、带字节顺序标记的 UTF-16 和 GB18030，可在转换选项手动指定。
- Markdown：支持常用标题、列表、表格、代码块及基础强调，不等同于完整扩展 Markdown 浏览器。
- TIFF：多页图像保留全部页面。
- 网页：点击工具栏网页按钮，打开地址，必要时在应用中登录，待内容完整后加入批次。保存的是当前网页布局的分页快照，不执行专门的 `@media print` 排版；特别高的图片或其他元素可能跨页，懒加载内容应先展开。
- 本地 HTML：保留常见同名 `_files`、`.files` 资源文件夹。其他位置的相对资源或远程资源须在预览中核对，不保证任意资源树完整归档。

未知格式显示不支持原因，不会伪装成已转换。

## 暂停、取消与恢复

“暂停后续任务”停止新的输出，不代表能立刻停止打印机出纸。取消所选任务只针对本应用任务；已经完成的 PDF 保留。

退出应用后，已经提交给系统的打印任务可能继续执行。重启会先核对执行记录，不会自动重发结果不明的任务。

“需核实”表示提交响应丢失、系统历史不可用或无法确认结果。请检查打印机与输出目录，再决定是否创建重打任务。重打可以保留全份，也可在新任务的页码范围中指定补打页面。

“系统完成”仅表示 CUPS 报告完成，不能证明每张纸都已正常输出。不要将队列状态当作现场出纸核验。

关闭窗口不会退出程序；从应用菜单选择退出才会停止新任务调度。

## 历史与本地数据

数据保存在当前用户的 `~/Library/Application Support/BatchPrint/`。包含 SQLite 历史数据库、源文件快照、转换 PDF 和预览文件。

默认内部缓存保留 30 天，历史记录保留 180 天；通过设置页“清理过期数据”清理。运行中、待执行及需核实的任务会受到保护。用户导出的 PDF 位于所选目录，不受历史清理影响。

缓存已经过期的历史记录不能直接重打，需要重新导入原文件。导出日志可能包含文件名、本地路径和输出记录，分享前请自行检查内容。

## 常见问题

- 没有 LibreOffice：PDF、图片、文本和网页仍可用；办公文件需要完成安装引导。
- 页码范围错误：清空表示全部页面，或按转换后的总页数重新输入。
- 打印机不支持参数：更换纸张、颜色或单双面设置；必要时检查系统驱动。
- Office 超时：默认 180 秒，可在设置中调整；只有本应用启动的独立转换进程会被停止。
- 无法保存 PDF：检查目录权限与磁盘空间，重新选择目录重试。
- 历史数据损坏：应用停止写入保护现有数据库；先备份数据目录，再排查，不能将损坏数据当作空历史覆盖。


## 删除任务与批次（1.0.1）

- 删除文件任务：先点击中间列表中的文件，再点击列表底部“删除任务”；按住 Command 可多选。也可以右键选择“删除任务”。
- 删除整个批次：选中左侧批次，点击左下角“删除当前批次”，或右键批次选择“删除批次”，然后确认。空批次也能删除。
- 删除后，列表底部显示“撤销”，可恢复本次会话最近一次删除及原有顺序。退出应用后不能再撤销。
- 删除移除应用内任务和历史记录，不删除原始文件或已经导出的 PDF。内部缓存按保留策略清理。
- 转换、导入或输出期间暂不允许删除；系统排队、处理中、提交中或“需核实”的记录不能删除，以便继续核对打印状态。

“取消”停止任务但保留记录，“删除”移除记录。已取消的文件不会直接输出：选中文件，右键“再次输出 / 重试”，等待重新准备后点击“保存 PDF”或打印按钮。

升级前退出旧版应用，将新版替换到原安装位置。应用数据保留；请从新版应用重新打开，避免继续使用旧窗口。
