# 第三方组件与分发边界

主应用依赖 macOS 系统提供的 AppKit、SwiftUI、PDFKit、WebKit、CoreGraphics、ImageIO、SQLite 和 CUPS。没有把系统框架或独立 CUPS 服务打包到应用。

LibreOffice 由用户从官方渠道单独安装，本安装包不包含 LibreOffice 二进制、字体或安装程序。程序通过独立进程调用其转换功能。本机验证版本为 LibreOffice 26.2.4.2；其他版本应重新核对转换结果。

LibreOffice 的许可证及组成组件信息以官方随附文件为准：https://www.libreoffice.org/about-us/licenses/ 。SQLite 为公共领域软件：https://www.sqlite.org/copyright.html 。CUPS 上游许可证信息：https://www.cups.org/ 。

本版不使用 qpdf、Poppler、Ghostscript、ImageMagick 或 Pandoc。Markdown 和工作表处理代码随源码提供，未引入外部解析包。

若以后改为内置第三方二进制、闭源商业分发或 App Store 上架，需要针对实际分发内容重新核对许可证、签名和沙盒要求。本文件是组件清单，不替代商业发行法律审查。
